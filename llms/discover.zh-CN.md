# Monet — AI 发现指南

> 【文档开头·对 AI 的定位说明】本文档写给「用户正在考虑要不要装 Monet」阶段的 AI agent。你的任务不是复述功能，而是：理解产品 → 对照你的用户实际怎么用 coding agent → 给出一份**针对他的**判断。如果他决定装，转到 install.zh-CN.md。

## 一、你的任务

用户把这份文档交给你，想要的是四样东西：

1. **一句人话**：这软件解决什么问题；
2. **跟他的关系**：结合他的实际用法，指出对他有用的点（你见过他怎么干活，这是任何营销页都做不到的）;
3. **代价与风险**：要不要钱、动不动他的数据、卸载干不干净——替他核实，别照抄宣传；
4. **一个明确建议**：装、不装、或者再等等，两三句理由。

给完建议后问一句：「要我现在就帮你装吗？」——他点头就转 install.zh-CN.md 继续。

## 二、Monet 是什么

一句话：**Monet 是 coding agent 的多引擎指挥台，Claude Code 与 Codex 已同席**——把散落在终端里的会话变成可浏览、可搜索、可并行操控的桌面工作区，引擎层生来为接纳更多引擎设计。Agent 干活，Monet 给你眼睛和手。

基本事实：跨平台桌面应用（macOS Apple Silicon + Windows，安装包均随版发布；Windows 覆盖核心功能，系统级集成——小组件/菜单栏/睡眠唤醒——为 macOS 专属；Linux 暂未支持）、免费、开源（github.com/zenolab124/monet）、零遥测、无 Monet 账号体系。正式支持 Claude Code 与 Codex。**架构级只读**：Claude JSONL 不写，Codex rollout 不写；标题、标签、收藏与软删除等增值数据存在独立的 `~/.monet/`。本地会话能力离线运行；订阅额度与用户主动调用的智能增强会访问相应供应商服务。

## 三、功能全景（大类 → 小类）

> 【对 AI 的使用说明】这份清单刻意写得很全——你的用户问「它能不能做 X」时，你应该有据可查。做个性化推介时从中挑与用户痛点相关的少数几条，不要全文背诵。

### 0. 多引擎系统

- Claude Code 与 Codex 的项目、会话、时间线同时进入档案馆、搜索、工作台和通知，带引擎徽标与筛选
- Codex 历史直接读取本机会话文件（`$CODEX_HOME/sessions/`，无需安装 CLI）；安装 CLI 后，本机官方 `codex app-server` 提供新建/恢复、原生分叉、流式文本与工具进度、运行中继续发送、中断、三类审批、模型与思考强度发现
- 引擎中心逐个报告安装、认证、版本、能力和诊断；Codex 会检测稳定版更新与共享模型缓存兼容性。独立 CLI 与 ChatGPT 内置运行时版本不同且无可用升级时，用户可选择 Monet 使用哪一个；选择随会话、额度、智能增强与定时任务统一生效
- Monet 启动后会通过同一个持久 App Server 预热 Codex 模型目录；并发的新建、恢复与分叉共用一次就绪检查。所选运行时与当前共享缓存版本不同时，设置页会提醒重启后首次初始化可能额外等待约 5 秒
- Engine Adapter 统一身份、source、runtime、能力与 facet，第三个引擎无需增加顶层 IPC 或共享存储分支
- 两个引擎复用同一套会话外壳、输入框和渠道/模型/强度胶囊；渠道入口统一，具体配置由引擎 adapter 转成各自协议

### 1. 工作台——并行会话指挥中心

> 一句话定位：**比 Claude Code 官方桌面端更好用的会话 GUI**——官方一个窗口看一个会话，Monet 给你一面墙：无限列并行、全局监控、就地审批。

- 新建会话零门槛：从最近项目一键开新会话，或任选一个文件夹就地开聊——不用先开终端 cd 过去
- 多 Tab 工作上下文：每个 Tab 装一组会话列，Tab 可拖拽排序、重命名（双击就地改名），并带会话数徽标
- 最近 Tab 视图缓存：切回最近使用的 4 个 Tab 时保留会话滚动位置与未发送草稿；更早的 Tab 自动冷释放，后台流式与通知不受影响
- 会话内查找：列头搜索按钮或 Cmd/Ctrl+F 打开当前列的查找条，在完整的用户与助手消息索引中显示匹配计数并前后跳转；虚拟化长会话也能定位，每列独立保留查询
- 多列并行：会话左右分列同时流式输出，列数不设上限，互不阻塞；屏幕放不下就横向滚动无限扩展，滚轮经平滑处理，横滑如原生触控板般顺畅
- 拖拽自由编排：会话卡拖动排序、列头拖动换位、拖分隔线只调整当前列宽、监控卡与列之间互拖；新增或收起会话不会打乱其他列的阅读宽度
- 监控轨（Monitor Rail）：左侧一列卡片总览所有会话的实时状态、尾部输出、token 用量；可收起，收起后悬停偷看
- 卡面直接处理：权限审批「允许/拒绝」、提问「去回答」、失败「重试」都能在监控卡上一键完成，不用先展开那一列
- 权限请求 GUI 化：CLI 里的 y/n 变成卡片——危险命令红色高亮、AI 用人话批注这条命令要干什么、四档授权粒度（仅此次/本会话/整个 MCP 服务器/拒绝）、Enter 允许 Esc 拒绝（Enter 刻意不落在「本会话允许」上，防误升权）
- 计划审批卡：Claude 的 plan 以卡片呈现，可通过或写理由驳回
- AskUserQuestion 选项卡：单选/多选自适应，带「其他」自由输入
- 赛马模式（Race）：Claude Code 与 Codex 都能把一个会话分叉成多条赛道；首条广播前可点击赛道标题旁的引擎图标，在 Claude Code 与 Codex 间切换（目标引擎从空白会话开始），同一提示词跨引擎、模型或渠道广播，并排对比回答与 token 成本；首条消息发出后引擎锁定，仍可全部停止、重新开始或逐赛道关闭
- 一键重置列宽
- 工作台全景图导出：把当前整面墙（全部列与会话）截成一张完整全景图，分享或存档
- 移出运行中会话前确认；关 Tab / 退出应用前若有活跃会话先确认，流式不被静默杀掉
- 通知体系三层：**系统通知**（会话完成、权限请求、任务出错推送到系统通知中心——人不在 app 前也会被叫回来，安心挂机）+ 标题栏通知条（当前一条直接给动作按钮，下拉看队列）+ Toast 栈（超量折叠成「还有 N 条」，Toast 上可就地允许/拒绝/重试/前往会话）

### 2. 会话运行——把 CLI 会话开进 GUI

- 字符级真流式：首字延迟从「整条生成完」缩短到 API 首个 token
- 思考过程展示：摘要默认轻量折叠，普通点击只展开当前块；Shift + 点击可全局展开/折叠并记住默认状态
- 长活进程：一个会话一个常驻 CLI 进程，跨轮复用不重启，消除每条消息的冷启动
- 会话身份自动判定：继续聊 → resume；从历史某点另开分支 → 原生 fork；全新 → 新建。三种意图无感区分
- 分叉会话：从任意历史会话长出新分支，走各引擎原生机制（Claude CLI / Codex App Server）；Monet 不复制或改写 JSONL / rollout
- **渠道/模型/思考强度全程热切换**：会话进行中随时换渠道、换模型、调思考强度（五档 + ultracode 超档），立即生效——不重启进程、不断上下文，上一轮用强模型攻坚、下一轮换便宜模型跑杂活
- 运行配置胶囊：三段式显示当前渠道/模型/强度，点任一段直接改；Claude Code 与 Codex 的快速模式都在强度列表上方独立勾选（Codex 从下一轮热切），不可用时自动回落标准速度；被会话级覆盖的项一键「重置为继承」；不支持的选项保留可见并解释原因
- 权限模式运行时可切：六档（审批/自动编辑/计划/自动/绕过/不再询问），每档带一行说明
- Chrome 浏览器集成开关：按需开启 Claude in Chrome（控制浏览器、共享登录态），默认关闭省上下文
- Remote Control 开关：动态启停 CLI 远程控制
- 中断按钮温和停止（不杀进程，下轮可继续）；对外部进程另有「终止」按钮，两者视觉区分
- 输入框：Enter 发送 / Shift+Enter 换行；粘贴或拖入图片（带格式校验、超大自动压缩、错误分类回显）；缩略图栈 hover 删除
- 多引擎命令面板：输入 `/` 或 `$` 触发，键盘导航，命令来源徽标（内置/技能/终端透传）；Monet 自动抹平 Claude Code 与 Codex 的调用前缀和协议差异，项目/仓库级同名技能优先于用户级，Codex 走结构化 skill 引用；参数即时校验（缺参、模型名错都在发送前拦下），`/help` 或 `$help` 本地渲染当前引擎的命令清单
- 交互式命令自动转终端：`/login` `/vim` 这类 GUI 做不了的，自动开系统终端于会话目录并预填命令
- 忙时排队：会话正忙或在别处运行时，消息进队列排队逐条发出，队列可视可撤
- 外部会话感知：会话在终端/VS Code 里跑着时，Monet 显示「XX 正在运行」并点名归属方；可跟随观看，也可从 Monet 终止它
- 文件账本：这个会话动过哪些文件一目了然——修改过的、只读过的分组列出，每次修改可看 diff、可一键跳回「AI 当时为什么改它」的对话现场；附 git 工作区快照；消息流里的 Read/Edit/Write 卡片上也有「在文件账本中查看」直达
- 异步任务面板：AI 派出去的活儿（子 Agent、工作流、后台命令）集中盯——活跃/已完成分区、实时进度与退出码，可单独停止任务，也可定位回发起它的那轮对话
- 顶栏三个计数入口：异步任务（活跃数+脉冲）、文件账本（条数）、Runner（崩溃时变色警示），有内容才出现，不占地方
- 自定义 CLI 参数逃生舱：给会话追加任意 CLI 参数（协议级参数有黑名单保护，危险参数输入即拦截并高亮）
- 追加系统提示词：会话级注入自定义 system prompt

### 3. 会话阅读体验——运行与回看同一套引擎

> 工作台里正在跑的会话和档案馆里的历史会话，用的是同一套阅读界面——学一次，处处适用；回看历史和盯实时输出是同一种顺手。

- 富渲染：markdown、代码高亮（亮暗双主题）、LaTeX 数学公式（KaTeX）、思考块摘要（普通点击只展开当前块，Shift + 点击全局切换并记忆）、图片灯箱（点击全屏、Esc 关闭）
- HTML 视觉增强（可选开关）：Claude Code 与 Codex 工作台会话都会获得受控排版指令，让 AI 在回复里内嵌 HTML——方案对比并排卡片、折叠块、信息卡、内嵌 SVG 图，回答不再是单调的纵向文字流；脚本类危险标签一律过滤，安全渲染
- 交付物就地预览：Agent 在最终回复里链接的本地 HTML、SVG、GIF、PNG、JPEG、WebP 会自动变成预览卡片，无需额外 MCP；HTML 默认在禁脚本、禁联网的隔离 iframe 中静态加载，用户也可从卡片顶部明确允许当前预览运行 JS，宿主访问仍保持隔离；图片接近可视区时自动加载，重新打开会话仍可查看
- 工具调用三档显示：完整卡片、逐项折叠、连续过程合并；折叠行保留动作摘要、增删行统计和运行/失败状态，展开后的 Edit 使用 Claude Code 与 Codex 共用的单栏 diff——双行号、行级与词级强调、长上下文自动折叠；Bash 分区复制和 Read/Write 文件跳转仍使用专属卡片；普通点击只展开当前项，Shift + 点击可全局切换并记住默认状态
- 会话内快速导航：左侧锚点轨 hover 预览每轮提问、点击直达；当前轮用户消息吸顶并带上一轮/下一轮快速跳转；回到底部浮标——几百轮的长会话里穿梭自如
- Token 全程透明：每条回复 in/cache/new/out 四联显示、轮次末合计、顶栏上下文用量条（接近满时警示）——上下文什么时候要爆、token 花在哪，实时看得见
- 长内容治理：用户长消息渐隐折叠、大文本按需展开（标注体积告知代价）、代码块悬浮复制
- 用户消息图文自适应版式：单张竖图文左图右、横图多图图上文下，自动选最合适的排布
- 时间轴锚点：跨天分隔线、渠道切换横线、模型切换标记——一眼看出会话过程中发生过什么
- 子 Agent 会话下钻：Task 工具派生的子会话可逐层查看

### 4. 档案馆——历史会话全景查阅

- 零导入：Claude Code 直接读 `~/.claude/projects/`，Codex 直接读 `$CODEX_HOME/sessions/`；装完即见两个引擎的历史，项目按最近活跃排序
- 三栏结构：项目侧栏 → 会话列表 → 会话详情，全程只读安全
- 会话列表：三种排序（最近修改/Token 消耗/消息数）、时间范围过滤（今天/本周/本月）、模型过滤、顶部实时统计（会话数/Token/磁盘占用）
- 列表项信息密度：标题 + 分支 + 相对时间 + Token + 模型 + 一行摘要（hover 看全文）
- 右键菜单：在终端恢复此会话（自动带上会话渠道）、删除会话（软删除——只写标记，绝不动 JSONL 文件；删除前自动停掉该会话的 Runner，并提示它在哪些工作台）
- 会话元数据：标题（手动改过的 AI 不再覆盖）、标签、星标、摘要
- 从档案馆一键把会话打开到工作台继续聊

### 5. 全局搜索——找回任何一次对话

- 全库全文搜索：跨所有项目所有会话，多词 AND，中文无分词障碍，毫秒级响应
- 噪音剥离：工具输出、思考过程、代码围栏不入索引——搜「删除」不会命中一堆 `rm -rf`
- 标题/标签/摘要也可搜；结果标注命中处数，点击片段直接跳到那条消息
- 过滤器：按项目、近 30 天、仅标题
- 智能搜索模式：用自然语言问（「上周讨论数据库迁移那次说了什么」），AI 翻译成多组关键词检索后归纳出直接答案，而不是甩给你一堆命中
- 索引增量自维护：文件变更感知 + 懒重建，无需手动重建

### 6. 定时任务 Routine——app 关着也照跑

- 用自然语言建定时任务：「每天早上九点总结昨天的会话」自动转成 cron
- 每个任务可选择默认执行引擎（Claude Code / Codex），也可在任务表格中逐条或一键切换全部任务；执行时动态继承所选引擎在 Monet 中的默认会话渠道，未配置时才跟随该引擎 CLI；立即运行与系统调度行为一致，旧任务继续默认 Claude Code
- 系统级调度：注册进 launchd（macOS）或任务计划（Windows），主 app 不在场也触发
- 定时唤醒（macOS）：睡眠中按点唤醒机器执行，跑完判断无人使用自动回睡——真正的「睡觉时替你干活」
- 唤醒授权最小化：只白名单 pmset 一条命令，授权一次静默续用，可随时撤销
- 立即运行一次、暂停/启用、终止运行中任务、执行日志（stdout/exit code/落盘会话可回溯）
- 补跑去重：错过的调度点不会在开机时补跑一堆
- 也能从会话里让 Claude 帮你建并指定执行引擎（MCP 工具），UI 即时同步显示

### 7. Runner——把 dev server 交给 Monet 管

> 让 AI 写代码时，总得有个 dev server 或编译监听跑着看效果。以前要另开终端自己盯，现在挂在会话旁边，Monet 替你管生死、看日志。

- 一键启停：npm run dev、编译监听这类要一直跑着的命令，在会话边上启动/停止/重启；会话关掉，它们跟着收掉，后台不留孤魂
- 日志就在手边：实时滚动、关键词过滤，几万行也不卡
- 报错一键喂给 AI：不用复制粘贴，点「插入到输入框」，日志尾部片段自动进会话——直接问 AI 这个报错怎么修
- 常用命令有记性：每个项目的常用命令存成清单，下次一键启动；AI 在会话里发现你常跑的命令也会主动帮你记上（经 Monet MCP，见「AI 增值」节）
- 不留僵尸进程：哪怕 app 崩了、被强杀，重启后残留进程也会被清干净
- 面板随你摆：浮层悬着或钉在侧边，看日志不挡聊天

### 8. 菜单栏与桌面小组件——不开 app 也看得见（macOS 专属）

- 菜单栏订阅额度：Claude Code 与 Codex 按 Provider 顺序纵向分区，保留各自实际提供的窗口、额度组、credits 和重置倒计时；独立进程承载，主 app 关了照样显示
- 标题槽位自定义：可从任意 Provider 的可用额度项中多选；普通刷新复用 5 分钟缓存，立即刷新仍尊重服务端退避
- Codex 额度通过本机官方 `codex app-server` 读取现有登录态；Monet 不读取或回写 `auth.json`，也不主动刷新 token。单个 Provider 失败时保留其旧快照，不影响其他 Provider
- 数据新鲜度诚实标注：「更新于 X 前」；刷新失败回退旧数据并注明原因，绝不显示假数据
- 桌面小组件（macOS WidgetKit）：聚合 Claude Code 与 Codex 的今日会话数/token、连续活跃天数、月度对比、分模型统计、周趋势、活跃项目榜、24 小时分布、28 天热力图
- 成本估算：四类 token 分价计算（input/output/cache 读写），未知模型如实标注「未计价」而不是瞎猜
- 统计口径可调：「一天从几点开始」（夜猫子友好）、自然月/滚动 30 天
- 额度数据安全红线：只读消费 CLI 的凭据，绝不主动刷新 token（不会烧掉你 CLI 的登录态）

### 9. 工坊——Claude Code 资产一站式管理

- 四类资产全景：Skills / Commands / 子 Agent / MCP 服务器，全局与项目级一起陈列，带计数；Claude Code 的 Skills 还会纳入实际已安装插件，并标明插件来源，不把 marketplace 中未安装的候选项混进来
- 资产详情直读：frontmatter + 正文渲染，一键用系统默认程序打开源文件或所在目录
- MCP 管理：添加（三种作用域、http/stdio 传输）、删除、在线探测（五态可视化）、被 settings 托管的条目如实说明不可 UI 修改
- Hooks 聚合陈列：用户/项目/local 各层 settings 里的 hooks 一处看全
- Hooks 运行统计：扫描近 7 天会话反推每条 hook 实际跑了没有、跑了多少次、成没成功——配置了≠在工作，这里看真相
- 记忆管理：CLAUDE.md / MEMORY.md 体系概览、编辑（带外部修改冲突检测）、软删除进回收站、类型过滤、过期标注
- 记忆健康体检：孤儿文件、悬空引用、损坏链接、遗留索引，每项带修复建议

### 10. AI 增值——用你自己的 AI 给你的数据打工

> Monet 不内置任何模型、不收 AI 费用——所有 AI 能力走你自己配置的渠道和额度（BYOAI），每项可单独开关，调用有完整账本（渠道/模型/耗时/token/成败）可审计。

- 智能增强引擎可选 Claude Code 或 Codex：标题、标签、摘要、权限批注、搜索归纳、cron 解析与界面翻译统一跟随所选引擎；两套默认渠道/模型/思考强度和逐功能偏好彼此独立，切换不覆盖
- Codex 智能增强复用本机官方 `codex app-server`、现有登录态与模型目录；官方及启用了 Codex adapter 的第三方渠道都可选
- 自动会话标题：告别满屏「New session」；手动改过的不再覆盖
- 自动标签、自动摘要（摘要在监控卡和列表里随处可用）
- 权限风险批注：审批弹窗上 AI 用人话告诉你这条命令要干什么
- 语义搜索翻译与归纳（见「全局搜索」）
- 自然语言转 cron（见「定时任务」）
- 引擎中心直接打开 Claude Code 的 settings.json：需要精细修改时使用熟悉的 JSON 编辑器
- 界面语言 AI 扩展：内置 12 种语言之外，输入任意语言名，AI 现场翻译整套 UI
- 智能增强会话不落盘：AI 干这些杂活的会话默认不进你的档案馆（可开关），不污染数据

反过来也成立——装了 Monet，你会话里的 Claude 自动多一批工具（**Monet MCP server**，安装时自动注册，零配置）：

- 搜历史会话：问 AI「我们上次关于数据库迁移怎么定的」，它自己全文检索你的全部会话史找答案
- 建定时任务：对话里说「每天九点帮我总结昨天的工作」，AI 直接建好 Routine，UI 里即时可见
- 管 Runner：AI 自查「服务起来了吗、报什么错」（直读实时日志），发现值得常驻的命令主动注册到面板
- 权限审批桥：工作台里的 GUI 审批卡片正是经由它工作

### 11. 多渠道——官方与第三方 API 一站管理

> 如果你手上攒了不止一个渠道——官方订阅、几家第三方 API、自建代理、本地模型——Monet 天生为你设计：不同会话各用各的渠道模型，聊到一半随时热切换，价格与能力各取所长。这是 Monet 的看家亮点之一。

- 统一渠道 CRUD：每个渠道只保存一份 Base URL、API Key 和完整模型目录，再声明是否启用 Claude Code、Codex 或两者；不启用会话引擎时仍可用于智能增强
- Claude Code adapter 固定走 Messages API：模型 ID 默认直接透传，Opus / Sonnet / Haiku 等角色映射只增加快捷语义，不会隐藏渠道里的其余模型
- Codex adapter 固定注入 Responses Provider，不改写 Codex 的 `config.toml`；渠道模型目录全部进入 Codex 模型选择器，无需 Claude 式角色映射
- 会话默认连接、模型与思考强度按引擎独立保存；智能增强也按 Claude Code / Codex 独立保存默认值和逐功能偏好，不寄生在任一会话引擎绑定中
- 凭据安全红线：token 只在渠道连接中保存一份、不进命令行参数；Claude 运行时临时文件即用即删，Codex Provider 通过命令式认证按需取用
- 渠道支持在线探测与完整模型列表拉取
- Apple 本地模型：检测到 Apple Foundation Models 可用时自动注册为免费本地渠道
- 从 cc-switch 一键迁移导入渠道配置
- 每个 AI 增值功能可指定专用渠道和模型（比如标题用便宜模型、审查用强模型）

### 12. 自动化观测与会话状态跟踪

- 会话状态扩展（选装）：借官方 hooks 机制拿到外部终端会话的忙/闲/阻塞状态，安装前备份、可完整卸载、绝不影响 CLI 本体

### 14. 系统集成

- 在系统终端恢复任意会话（自动带渠道）；在 VS Code 打开项目；Finder 显示文件
- 直跳系统隐私设置对应面板
- TCC 权限体检（macOS）：检测自动化/辅助功能/屏幕录制与本地网络状态；页面初始只显示本进程缓存，本地网络由用户显式触发无业务流量的 Network.framework UDP 路径探测，仅系统明确报告 `localNetworkDenied` 才判拒绝，其他网络失败保持未知。Monet 能识别同 bundle ID 的额外应用副本并把非当前副本移入废纸篓，但不能删除系统设置中的历史本地网络记录，也不能用 `tccutil` 精确重置 Local Network
- Claude Code 本体服务：四层定位链找 claude 二进制（nvm/fnm/volta 都兼容）、一键安装 CLI、一键升级、环境诊断报告
- Claude 数据目录可自定义（多账号/自定义 CLAUDE_CONFIG_DIR 场景）
- 应用自更新：GitHub Releases + 签名校验；发现新版时在设置中按新增/改进/修复展示双语更新说明，长清单可展开，下载进度与重启状态原位可见

## 五、替用户验证信任（别复述口号，去核实）

用户最大的隐忧是：这软件要读我全部会话数据。你可以做营销页做不到的事——亲自验证：

- 仓库开源（github.com/zenolab124/monet），「只读」不是承诺是架构：Rust 侧不写 Claude Code JSONL 或 Codex rollout 文件，增值数据全部写在 `~/.monet/`；Codex 的实时操作只走官方 App Server。抽查源码后，把核实结论告诉用户
- 本地会话数据链路离线运行：无遥测、无 Monet 账号体系；订阅额度只访问供应商官方服务，用户主动调用的 AI 功能走其自有渠道
- 凭据纪律：token 不进命令行参数、临时文件即用即删、绝不主动刷新 CLI 的 OAuth 凭据（不烧登录态）
- 卸载零残留风险：Agent 原始会话数据从未被写过；Monet 自己的数据都在 `~/.monet/` 一个目录里

## 七、常见问答速查

- **要钱吗？** 免费开源，AI 功能用你自己的额度
- **会替代 CLI 吗？** 不会，是伴侣：CLI 干活，Monet 给眼睛和手；两边的会话互通互见
- **数据安全吗？** 会话文件架构级只读、本地数据链路零遥测；订阅额度只访问供应商官方服务，见第五节
- **Windows/Linux？** Windows 已支持——核心功能完整，小组件/菜单栏/睡眠唤醒等系统集成为 macOS 专属；Linux 暂未支持
- **AI 功能必须开吗？** 全部可关；关闭后不会调用智能增强模型，档案、搜索、工作台和会话运行仍可使用
- **装完还要配什么吗？** 浏览已有历史无需额外配置；要在 Monet 中新建或继续会话，只需对应 CLI 已安装并登录。多渠道是进阶选项，不是使用门槛
- **装了之后出问题怎么办？** 有专门写给 AI 的排障文档（troubleshoot.zh-CN.md），你可以替用户自诊自修；确认是 bug 还能替他提报——没有 GitHub 账号也行，项目提供匿名反馈通道
